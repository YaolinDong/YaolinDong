Languages and Tools — official logo sources

All displayed logos were downloaded from official project repositories, brand
resource pages, or official documentation/websites. sources.json records the
source URL, evidence page, SHA-256 of the original bytes, and the badge using it.
The logo record retains the original source and its SHA-256. The embedded_asset
record identifies the optimized artwork actually embedded in each badge.
Redundant SVG metadata is removed with SVGO 4.1.0. Oversized raster originals
are resized proportionally with sharp 0.35.5 to at most three times their display
dimensions and encoded as lossless PNG. Smaller originals are not enlarged.
There is no recoloring, redrawing, or cropping. Some dark logos sit on a white
mount inside the existing colored badge so the official artwork remains legible.
The unoptimized originals remain in Git history at commit
5736e7f9438229e14421e08162719d3654246f9b, before this optimization.

CAN FD uses the official CAN in Automation (CiA) association mark from can-cia.org.
It is an association logo, not a separate CAN FD protocol logo. STM32 uses the
official STMicroelectronics mark distributed with STM32 documentation. ROS 2
uses the official ROS project logo. Website and documentation icons are identified
in sources.json rather than being described as separate product brand kits.

Pinocchio: original logo from gepetto.github.io/doc/pinocchio/doxygen-html/pinocchio.png
Ruckig: original logo from docs.ruckig.com/logo.png
C: original logo from www.c-language.org/logo.svg. WG14 links this official
language homepage, whose FAQ describes the traditional C logo and its provenance.
https://www.c-language.org/faq
SolidWorks: complete official vector wordmark from
https://www.3ds.com/assets/3ds-navigation/3DS_corporate-logo_solidworks.svg
Displayed on a borderless white badge with the original brand-red artwork,
replacing the low-resolution website favicon. No cropping or recoloring.

AutoCAD: official inline SVG from the "Explore the AEC Collection / Products
included" section of https://www.autodesk.com/products/autocad/overview .
The original SVG is preserved in assets/logos/autocad.svg. The badge identifies
AutoCAD specifically, replacing the previous generic CAD text-only badge.

3D Printing and PCB Design have no confirmed official logo selected and
remain text-only, including their Chinese variants.
No Simple Icons, Devicon, or self-drawn functional symbols are used by these badges.

Labels, colors, and text metrics retain the existing Shields.io badge design.
JAX, Flax, and MuJoCo source licenses are included alongside this file.
All project and vendor marks belong to their respective owners.
